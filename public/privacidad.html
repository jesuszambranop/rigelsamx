Formularios de contacto y empleo

Rigel México recibe los datos que proporcionas para responder tu consulta comercial o técnica. El formulario de empleo entrega tu perfil y CV al equipo de Recursos Humanos.

Contacto se dirige a ventasmexico@rigelsa.com. Las postulaciones se dirigen a rrhh@rigelsa.com. No incluyas documentos de identidad, datos financieros ni información sensible innecesaria.

Archivos adjuntos

Los CV se envían por correo como PDF adjunto. La web no conserva una biblioteca pública de documentos ni guarda el CV de forma permanente en el directorio del sitio. Los correos recibidos quedan sujetos a la gestión interna de Rigel.

Preferencias y seguridad

La elección manual de país puede guardarse en una cookie durante un año. El formulario PHP usa una cookie de sesión para proteger el envío. El servidor limita intentos usando una referencia hash de la dirección IP por periodos cortos. Puedes borrar estas cookies desde tu navegador.

Servicios externos

WhatsApp, GitHub Pages, Google Maps y los sitios regionales tienen sus propias políticas. Esta web no integra publicidad ni herramientas de analítica. El proveedor de alojamiento puede procesar registros técnicos necesarios para prestar el servicio.

Consulta, corrección o eliminación

Para consultar el tratamiento de tus datos o solicitar acceso, corrección o eliminación, escribe a ventasmexico@rigelsa.com. Rigel revisará tu solicitud conforme a su procedimiento de atención.
