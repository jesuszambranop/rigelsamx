Dates and batch codes with M1: from your first message to consistent printing

A legible date starts before you touch the screen. The content, print area and handling method need to work together so each impression identifies your product correctly.

By Rigel Mexico · November 23, 2026 · 4 min read

Define the data that identifies your product

M1 takes the message to the package: configure it on the touchscreen, then move the printer manually over the surface. This flexibility is useful when you work with different pack formats or move between workstations. Start with a print specification for each product rather than editing text from memory during a shift.

Separate fixed information, such as an internal reference, from variable information such as the date and batch number. Define who approves those values and where they come from. The printer reproduces the configured content; expiry dates and batch allocation must come from your company’s quality process.

DataDecision before printing
DateFormat, meaning and approved value for the production run.
BatchAn identifier linking the pack to its production record.
Fixed textClear abbreviations and an approved template for each pack format.
Barcode or QR codeContent, dimensions and the reader used to validate the application.

Design for the actual print area

M1 has a 3.5-inch touchscreen and a 12.7 mm print height. That height helps you plan a message, but you still need to measure the usable area: a cap, bottle and carton provide different support and travel paths. Choose a continuous area without folds, seals or abrupt changes in level.

Prioritize legibility. A concise message with adequate line spacing and clear labels is easier to inspect than crowded content. If you need text and a machine-readable code, prepare both at their final dimensions and inspect the physical result; a screen preview cannot reproduce substrate contrast or texture.

Set up a repeatable handheld operation

Consistency also depends on the workstation. Support the package so it cannot rotate or shift during the printing pass, and leave room to start and finish the movement. On curved surfaces, package support and print placement become especially important. Avoid changing the position with every unit.

Install S70 according to the printer and cartridge instructions. Test on the same substrate and finish you will use in production. Use a controlled movement and check proportions, alignment and spacing. Do not assume two operators will move identically; keep an approved sample at the workstation.

Approve the first sample and control changes

Before processing the full batch, compare the print with the production order. Read every character: a sharply printed date can still be wrong if the configured value belongs to another product. Also check placement and make sure the message does not obscure other package information.

Inspect the print after the drying time appropriate to the application and after normal handling. Record the substrate, template, consumable batch and result. Repeat the check when the pack format, substrate, message or operator changes, and during the shift according to your control plan.

  • Correct content: date, batch and reference match the order.
  • Complete print: no clipped, doubled or missing characters.
  • Stable placement: position and orientation are easy to inspect.
  • Suitable durability: the code remains legible during intended handling.

For machine-readable codes, check scanning too

A barcode or QR code needs more than a sharp appearance. Check the decoded content, contrast and clear space around the symbol. Keep it away from edges, folds and graphics that invade that space. Size must suit the code type and the environment in which it will be read.

Scanning a sample helps catch operational errors. Quality verification is an additional process using an appropriate verifier to assess the symbol objectively. GS1 distinguishes reading a code from measuring its quality. If your customer requires a verification result, include that requirement when evaluating the application.

What to send Rigel for a message review

Share a photo of the complete product, a close-up of the print area and the exact message you want to reproduce. Add the available dimensions, substrate and approximate units per shift. With that information, the Mexico team can review the M1 + S70 combination and help plan a representative trial.

Frequently asked questions

Can I use one template for every product?+

Only when the content, available space and printing conditions are equivalent. Use a separately approved template when any of those elements changes.

Does M1 assign my production batch?+

Define the batch in your production process. Configure the approved identifier on the printer and compare it with the corresponding record.
